# 证据与表述规则

## 什么算一条证据

可回溯到论文具体位置的原文或图表，至少满足一条：

- **图**：图号 + 图注原句 + 页码（`kind="figure"`）；
- **表**：表号 + 表注 + 页码（`kind="table"`）；
- **章节**：章节名 + 原文短句 + 页码（`kind="section"`）；
- **正文/摘要**：原文短句 + 页码（`kind="text"`）；
- **公式**：编号 + 页码（`kind="equation"`）。

`quote` 摘原文 10–40 词，不改写、不拼接两处不相邻的句子。

## 页码

用 PDF 物理页码（`paper.json` 的 `page`），不是期刊印刷页码。跨页图表以图注所在页为准。

## 图表

- 图注、表注原样保留编号、单位、误差棒说明；
- 示意图（conceptual figure）不得作为实验数据陈述；
- 引用他人结果时写"文献 [n] 报告"，不写成"本文发现"；
- 表格数值以渲染图（`tab_*.png`）为准，解析出的单元格仅在可信时使用；
- 图表编号与正文引用必须对得上：讲"图 3"时页面必须挂 Figure 3。

## 主张强度

| 证据 | 用词 |
|---|---|
| 论文明确报告的结果 | "报告/达到/表明" |
| 单一数据集、单次实验 | "在该数据集上" |
| 作者推测、未来工作 | "作者预期" |
| 自己的推断 | "本页为分析，非原文结论" |
| 未验证 | 不写，或进 `uncertainty` |

不把"可能"写成"证明"，不把"相关"写成"导致"。

## 数字

- 保留原文有效数字与单位，不四舍五入、不换算（除非同时给原值）；
- 百分比与绝对值不混用；提升幅度注明基线；
- 训练成本、样本量、参数量注明口径（如"8×P100，3.5 天"）。

## 讲稿备注

好备注 = 页面没写的信息：

- 过渡："下一页回答上一页留下的问题——单头会掉多少？"
- 强调："这个数字是全文最关键的一句，因为它同时赢了质量和成本。"
- 追问预案："如果被问为什么除以 √d_k，答：点积方差随维度线性增长。"

坏备注：把要点再念一遍；写"本页介绍了……"。

## 不确定性

以下必须写入 `result.json` 的 `uncertainty`：

- 图未抽出、用文字替代的页；
- 表格单元格解析不可信、改用渲染图的页；
- 模板占位符不足、回退内置版式的页；
- 未渲染（无渲染器）或渲染异常；
- 论文未报告、但汇报需要的数据。

每条写"缺什么 + 影响哪一页 + 评审如何复核"。

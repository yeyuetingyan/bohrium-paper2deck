# CiteManager：参考文献与引用管理 Skill

核验并重排学术稿件的引用：解析 BibTeX / RIS / 编号制文献表，按首次出现重排顺序编码制编号，按 DOI 与题名去重，按 GB/T 7714—2015 生成文末表，并检出悬空引用、未被引用条目与元数据缺失。属于玻尔产品周赛北化分站赛第一期「写作04｜参考文献与引用管理」参赛作品。

## 1. 适用条件

- 输入有稿件与文献库（至少其一），要求核对引用或整理文献表；
- 关心编号连续性、正文与文末表一致、重复条目、格式规范、字段缺失；
- 不适用：需要判断"这句该引哪篇"的学术判断；需要联网核验 DOI 真实存在；著者-出版年样式的字母序重排。

## 2. 依赖

| 组件 | 版本 | 用途 |
|---|---|---|
| Python | ≥ 3.9 | 运行 |
| 标准库 | — | BibTeX/RIS 解析、去重、格式化全部自实现 |
| `pymupdf`（仅 `paperkit` 的 PDF 分支用到） | ≥ 1.23 | 若稿件来自 PDF 抽取时需要 |

本 Skill 的引用流程**不联网、不依赖第三方文献库**。

## 3. 调用

```bash
python scripts/run_cite.py --case /input/case.json --out /app/output
python scripts/run_cite.py --manuscript paper.md --library refs.bib --out out
python scripts/run_cite.py --manuscript paper.tex --library refs.bib --format plain --out out
```

`case.json` 字段容错见 `SKILL.md`；`--library` 可重复传入多个库文件。

## 4. 产物

| 文件 | 说明 |
|---|---|
| `manuscript_revised.md/.tex/.txt` | 重排编号后的稿件；docx 输入转为 md |
| `references_gbt7714.txt` | GB/T 7714—2015 文末表，按新编号排序 |
| `references_deduped.bib` | 去重后的 BibTeX（字段互补合并后的结果） |
| `citation_map.json` | 旧号→新号、合并依据、未解析引用 |
| `check.json` | 悬空引用、未被引用、重复 DOI、字段缺失、待补引用候选 |
| `result.json` | 结构化结果与产物哈希 |

## 5. 方法要点

1. **原编号语义**：`[n]` 指文献库第 n 条（去重前），去重后通过 `old_index`/`aliases` 仍能落位；
2. **重排**：首次出现定序，区间压缩（`[1,2,3]`→`[1-3]`），只动标记不动句子；
3. **去重**：DOI → 题名相似度 ≥0.90 且同年 → 首作者+年，三档判据，逐一记录依据；
4. **GB/T 7714—2015**：姓氏大写、名缩写、>3 人 `et al`/`等`、类型标识、卷期页、DOI 形态；
5. **检查**：悬空引用（错误级）、未引用条目（警告级）、重复 DOI（错误级）、字段缺失（警告级）；含数字断言却无引用的句子进入候选清单。

## 6. 实测记录（合成样例，非正式案例）

样例刻意做乱：11 条文献（1 条重复、1 条缺年份、2 条未被引用）、正文 13 处引用（1 处悬空 `[12]`）。

| 指标 | 结果 |
|---|---|
| 去重 | 11 → 10（DOI 相同，`10.48550/arXiv.1706.03762`） |
| 重排 | 8 条被引用，按首次出现编号 1–8 |
| 悬空引用 | `[12]` 保留原样并报错 |
| 未被引用 | 2 条（含缺年份条目） |
| 输出 | 文末表 8 条、BibTeX 8 条、映射 8 行 |

## 7. 限制

- DOI 只查形态（`10.\d{4,9}/...`）与跨条目一致性，不联网验证存在性；
- 英文复姓、姓名缩写混写时切分可能不准，需抽查前 5 条作者；
- docx 只读不写，改稿需按 `citation_map.json` 回填；
- 编号制纯文本文献表的字段抽取是启发式的，抽不到的字段留空并在 `check.json` 报缺失；
- 不对"引用是否支持该论断"下结论，只输出需要人工确认的候选句。

## 8. 维护

- 版本 `citekit/1.0`（2026-11-25）；解析与格式化在 `scripts/citekit.py`，流程与产物在 `scripts/run_cite.py`；
- 新增文献类型只需扩展 `TYPE_TAG` 与 `format_gbt7714` 的分支；
- 已知用例：合成稿件 + BibTeX（11 条），验证去重、重排、悬空、未引用、GB/T 输出。

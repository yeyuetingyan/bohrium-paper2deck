# 示例稿件（合成数据，仅用于演示引用管理流程，不含真实科研结论）

Transformer 架构以自注意力替代循环结构，在机器翻译上取得显著提升 [3]。此前的工作依赖循环网络与卷积网络 [1]，训练成本高且难以并行 [2]。多头注意力把表示空间分解为多个子空间 [3]，位置编码补足顺序信息 [5]。在 WMT 2014 英德任务上，该模型取得 28.4 BLEU，超过此前最好结果（含集成）2 BLEU 以上 [4]。英法任务上单模型达到 41.8 BLEU [4]。有研究指出，自注意力的计算复杂度随序列长度平方增长 [6]，长序列场景仍受限。另有工作把注意力用于图像分类 [7]，显示出跨模态潜力。关于预训练语言模型 [8] 与稀疏注意力 [9] 的讨论，本文不再展开。需要指出的是，某份未列入文献表的报告也报告了类似结论 [12]。

综上，本文的贡献是：给出一个完全基于注意力的序列转换架构，并在两个翻译任务上验证其质量与训练成本优势 [4]。

# 核验口径（verification-rules.md）

本文件说明 `translate_assemble.py` 到底检查了什么、为什么这样定口径、以及哪些东西**故意不检查**。评分点"关系准 / 可核验"靠的就是这份口径：能被机器咬住的错误必须当场咬住，咬不住的要诚实标注，不冒充质量认证。

## 一、检查项与判据

| 检查项 | 判据 | 为何这样定 |
|---|---|---|
| `missing_translation` | `segments.json` 里的段号在译文里找不到对应条目 | 段号是版面对面位置的产物，漏段=交付不完整；这是"段落全"的第一道闸 |
| `identical_to_source` | 译文与原文逐字相同且原文不是目标语言 | 整段照抄原文是最常见的"假翻译"，必须显式暴露 |
| `target_not_cjk` | 源段是**成句英语**（≥5 个长度 >2 的拉丁词），而译文里 CJK 占比过低 | 只对成句段落生效：表格行、纯数字行、公式行豁免，避免"数字表格被误报" |
| `placeholder_left` | 译文里残留 `TODO` / `XXX` / `待翻译` / `[翻译]` / `…`（省略号独占） | 占位符混进交付物是最不该发生的事故 |
| `number_mismatch` | 原文数字多重集 ≠ 译文数字多重集 | 科学文本里数字就是结论；允许 `1.0≡1`、千分位、全角半角，但值必须一致 |
| `citation_mismatch` | `[12]` / `[12-15]` / `(Smith et al., 2020)` / `\cite{key}` 的多重集不等 | 引用是"关系准"的核心：改写成"有研究指出"就断了回查链 |
| `reference_mismatch` | `Fig./Table/Eq./Section` 编号不等，或译文既无中文标签也无英文标签 | 编号变了读者就找不到图表；允许"图 3"或保留"Fig. 3"，但不允许编号漂移 |
| `formula_missing` | 原文公式片段（上下标变量、关系式、`\cmd`、希腊字母变量）在译文里全部消失 | 公式里的变量名不是自然语言，必须搬过去 |
| `negation_lost` | 原文含否定/限定线索（`not/no/never/without/only/may/suggest/assume/partially`）而译文没有任何对应表达 | 把"未观察到显著差异"译成"观察到显著差异"是致命错误，宁可误报 |
| `term_not_locked` | 锁定术语出现在源段，译文却没出现对应译名 | 术语表是被执行的工件，不是建议 |

## 二、刻意宽容的地方

- **数字等价**：`1.0` 与 `1`、`1,000` 与 `1000`、全角 `１` 与半角 `1` 视为相同；
- **单位换写**：`28.4%` 与 `28.4 %`（多空格）相同；但 `512 ms` 译成"512 毫秒"会被 `number_mismatch` 的**单位后缀比对**记为差异，进 `unresolved`——这是故意的严格口径，让人确认一次而不是悄悄放过；
- **图号写法**：`Fig. 3` / `Figure 3` / `图 3` / `图3` 都算一致，只比数字；
- **连字与软连字符**：`ﬁ`/`ﬂ`、`\u00ad`、不间断空格在比对前归一；
- **已是目标语言的段**：`cjk_ratio ≥ 0.5` 的段标 `skip_translate`，原样保留并计入覆盖率，不参与"没翻译"的判定。

## 三、刻意不检查的地方（改写进 `result.json.uncertainty`）

1. **语义忠实度**：译文是否真的表达了原文意思——需要读懂领域才能判断，机器比对做不到；
2. **学术语气与文体**：是否保持了客观、被动/主动的选择、时态一致；
3. **长句切分与可读性**：中文长定语堆叠、逗号连缀的"翻译腔"；
4. **领域术语的正确性**：只保证"一致"，不保证"译对了"——若初始译名就错，全篇会一致地错。这条必须让使用者知道，所以写进 `uncertainty` 而不是藏起来；
5. **指代消解的正当性**：把 `it` 落实到具体名词是加分项，但落实得对不对只能人看。

## 四、指标定义

- `coverage_rate = 有译文的段数 / 应译段数`（`skip_translate` 的段计入分子与分母）；
- `invariant_pass_rate = 无任何不变量错误的段数 / 应译段数`；
- `term_consistency_rate`：见 `glossary-format.md`；
- `negation_kept_rate = 未触发 negation_lost 的段数 / 含否定线索的段数`；
- `status`：`ok`（覆盖率 100% 且不变量全过）、`partial`（有未译段或术语未锁定）、`failed`（材料不可读，如扫描件无文字层、加密 PDF）。

## 五、`unresolved` 与 `review.md` 的分工

- `check.json.unresolved`：机器可读，给脚本与自动化用，每条含 `seg_id` / `issue` / 期望值；
- `review.md`：人读，按段列出"原文摘句 / 当前译文 / 期望 / 建议动作"，供译者扫一遍就能改。

修改后**只需重跑第 3 步**（`translate_assemble.py`），切段结果不必重算——这样"核验—修正"循环的成本很低，也是本 Skill 能反复自我收敛的原因。

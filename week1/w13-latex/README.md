# paper-latex

把 LaTeX 工程改到「编译得通、改得对、交得可用、复现得了」，每一步都留证据。

## 设计原则

- **确定性优先**：括号配对、环境配对、表格列数、`\label`/`\ref`/`\cite` 闭环、数值不变量，
  全部用脚本算，不靠模型自述。模型只负责「怎么改」和「为什么这么改」。
- **诊断到文件与行号**：静态核验给行号；真编译时用日志里的括号嵌套栈解析出当前文件，
  再把 `l.NN` 归到该文件，连锁错误（`Emergency stop`、缺文件引发的瀑布）只**标注**不隐藏。
- **不变量记账只用一套归一**：所有比对走 `texkit.norm_hard()`（去标点、压空白、小写）。
  混用「保留标点」与「去标点」两套归一，会让 `2.1.0+cu118`、`data/x.yaml` 这类串永远匹配不上。
- **不变量范围显式写出**：`check.json.metrics.protected_scope` 说明「缺失」是在哪个范围内判的
  （默认只在主文件），避免把子文件被内联后产生的重复计数当成丢失。
- **锚点与引文分开**：`source_map` 里指向 `\label`/公式的条目是指针，不要求逐字；
  数值与论断类条目必须能在材料或交付稿里逐字找到。
- **诚实优先**：没有 TeX 引擎就写 `compile.status = "not_attempted"`，绝不伪造 PDF 或「编译通过」。

## 覆盖率

覆盖：结构（括号/环境/宏包顺序/表格/公式编号）、引用与文献闭环、数值与引用不变量、
交付完整性（六份交付物齐备且非空）、真编译（引擎选择、多轮、bib、日志解析与错误分类）、
复现计划完整性。

不覆盖（刻意不做，写进 `unresolved`）：论文用词与论证质量、公式语义正确性、
模板页边距字号行距的完整合规、PDF 排版美观、图像内容。

## 退出码

| 码 | 含义 |
|---|---|
| 0 | 正常完成（`status` 可能是 `ok` 或 `partial`） |
| 2 | 材料不可用（无 case / 无材料 / 空 / 读不出 / 无 `.tex`）或交付稿缺失 |

`reason` 取值：`no_case`、`no_material`、`empty_material`、`unreadable_material`、`no_tex`、`engine_timeout`。

## 目录

```
SKILL.md                 技能说明（写作协议、核验口径、降级表）
scripts/texkit.py        共用核：LaTeX 静态解析、TeX 工具链探测、多轮编译、日志解析
scripts/tex_prep.py      第一步：解析工程、清点编号与引用、行号级问题清单
scripts/tex_assemble.py  第三步：核验 + 真编译 + 导出
examples/                合成工程（带真缺陷）+ 已修好的六份交付物 + 日志夹具 + 反例清单
references/              字段字典、日志解析、不变量、核验规则
```
